O SearchGG 🔎

SearchGG to nowoczesna, lekka wyszukiwarka internetowa stworzona jako projekt działający na GitHub Pages.

Jak działa?

Wersja GitHub Pages korzysta z publicznego DuckDuckGo Instant Answer API. Dzięki temu może pobierać odpowiedzi, podsumowania i powiązane informacje.

SearchGG PRO 🚀

W przyszłości SearchGG może zostać rozbudowane o własny backend, crawler, indeks stron, ranking wyników, obrazy, wiadomości oraz własne API.
