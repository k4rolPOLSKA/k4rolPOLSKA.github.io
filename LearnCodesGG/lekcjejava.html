☕ 1. Czym jest Java?

Java jest popularnym językiem programowania używanym między innymi do tworzenia aplikacji, programów i różnych systemów.

public class Main { public static void main(String[] args) { System.out.println("Witaj w Javie!"); } }

🖨️ 2. Pierwszy program

Do wyświetlania tekstu w konsoli używamy System.out.println().

System.out.println("Hello World!"); System.out.println("LearnCodesGG");

📦 3. Zmienne

Zmienne pozwalają przechowywać dane.

String nick = "PlayerGG"; int punkty = 100; System.out.println(nick); System.out.println(punkty);

🔢 4. Typy danych

Java posiada różne typy danych, np. String, int, double i boolean.

String imie = "Karol"; int wiek = 13; double cena = 19.99; boolean online = true;

➕ 5. Operatory

Operatory pozwalają wykonywać działania matematyczne.

int a = 10; int b = 5; System.out.println(a + b); System.out.println(a - b); System.out.println(a * b); System.out.println(a / b);

❓ 6. if

Instrukcja if pozwala wykonać kod, gdy warunek jest prawdziwy.

int wiek = 18; if (wiek >= 18) { System.out.println("Pełnoletni"); }

🔀 7. if / else

else wykonuje kod, kiedy warunek if nie jest spełniony.

int wiek = 15; if (wiek >= 18) { System.out.println("Pełnoletni"); } else { System.out.println("Niepełnoletni"); }

🔀 8. else if

else if pozwala sprawdzić kolejny warunek.

int punkty = 80; if (punkty >= 90) { System.out.println("5"); } else if (punkty >= 70) { System.out.println("4"); } else { System.out.println("3"); }

🔁 9. Pętla for

Pętla for pozwala powtarzać kod określoną liczbę razy.

for (int i = 0; i < 5; i++) { System.out.println(i); }

🔄 10. Pętla while

while wykonuje kod dopóki warunek pozostaje prawdziwy.

int liczba = 1; while (liczba <= 5) { System.out.println(liczba); liczba++; }

📋 11. Tablice

Tablica przechowuje wiele wartości tego samego typu.

String[] jezyki = { "Java", "Python", "C#" }; System.out.println(jezyki[0]);

📚 12. ArrayList

ArrayList pozwala przechowywać kolekcję elementów, którą można modyfikować.

import java.util.ArrayList; ArrayList<String> gracze = new ArrayList<>(); gracze.add("Player1"); gracze.add("Player2"); gracze.add("Player3"); System.out.println(gracze.get(0));

⚙️ 13. Metody

Metoda zawiera kod, który możemy wielokrotnie wywoływać.

static void przywitaj() { System.out.println("Witaj!"); } przywitaj();

📥 14. Parametry metod

Metoda może otrzymywać dane za pomocą parametrów.

static void przywitaj(String imie) { System.out.println("Cześć " + imie); } przywitaj("Karol");

📤 15. return

return pozwala zwrócić wynik z metody.

static int dodaj(int a, int b) { return a + b; } int wynik = dodaj(5, 3); System.out.println(wynik);

🏗️ 16. Klasy

Klasa jest szablonem, na podstawie którego możemy tworzyć obiekty.

class Gracz { String nick; int punkty; }

👤 17. Obiekty

Obiekt jest konkretną instancją klasy.

Gracz gracz = new Gracz(); gracz.nick = "PlayerGG"; gracz.punkty = 100; System.out.println(gracz.nick);

🏗️ 18. Konstruktor

Konstruktor pozwala ustawić początkowe wartości obiektu podczas jego tworzenia.

class Gracz { String nick; Gracz(String nick) { this.nick = nick; } } Gracz gracz = new Gracz("PlayerGG"); System.out.println(gracz.nick);

🎮 19. Mini projekt

Stwórzmy prosty system punktów gracza.

int punkty = 0; punkty += 50; punkty += 25; System.out.println( "Punkty: " + punkty ); if (punkty >= 50) { System.out.println( "🏆 Dobry wynik!" ); }
