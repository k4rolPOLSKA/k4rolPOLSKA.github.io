🟣 1. Czym jest C#?

C# (czyt. „C Sharp”) to język programowania firmy Microsoft. Jest używany między innymi do tworzenia aplikacji, gier oraz usług.

Console.WriteLine("Witaj w C#!");

🧠 Quiz

Jak nazywa się język przedstawiony w tej lekcji?

🖨️ 2. Pierwszy program

Do wyświetlania tekstu w konsoli używamy Console.WriteLine().

Console.WriteLine("Hello World!"); Console.WriteLine("LearnCodesGG");

📦 3. Zmienne

Zmienne przechowują dane, które możemy wykorzystywać w programie.

string nick = "PlayerGG"; int punkty = 100; Console.WriteLine(nick); Console.WriteLine(punkty);

🔢 4. Typy danych

C# posiada różne typy danych, np. string, int, double i bool.

string imie = "Karol"; int wiek = 13; double cena = 19.99; bool online = true;

➕ 5. Operatory

Operatory pozwalają wykonywać działania matematyczne.

int a = 10; int b = 5; Console.WriteLine(a + b); Console.WriteLine(a - b); Console.WriteLine(a * b); Console.WriteLine(a / b);

❓ 6. if

Instrukcja if pozwala wykonać kod, gdy określony warunek jest prawdziwy.

int wiek = 18; if (wiek >= 18) { Console.WriteLine("Pełnoletni"); }

🔀 7. if / else

else wykonuje kod, gdy warunek if nie jest spełniony.

int wiek = 15; if (wiek >= 18) { Console.WriteLine("Pełnoletni"); } else { Console.WriteLine("Niepełnoletni"); }

🔀 8. else if

else if pozwala sprawdzić kolejny warunek.

int punkty = 80; if (punkty >= 90) { Console.WriteLine("5"); } else if (punkty >= 70) { Console.WriteLine("4"); } else { Console.WriteLine("3"); }

🔁 9. Pętla for

Pętla for pozwala wykonywać kod określoną liczbę razy.

for (int i = 0; i < 5; i++) { Console.WriteLine(i); }

🔄 10. Pętla while

while wykonuje kod dopóki warunek pozostaje prawdziwy.

int liczba = 1; while (liczba <= 5) { Console.WriteLine(liczba); liczba++; }

📋 11. Tablice

Tablica może przechowywać wiele wartości tego samego typu.

string[] jezyki = { "C#", "Java", "Python" }; Console.WriteLine(jezyki[0]);

📚 12. Listy

List pozwala przechowywać kolekcję elementów, którą można łatwo modyfikować.

List gracze = new List(); gracze.Add("Player1"); gracze.Add("Player2"); gracze.Add("Player3"); Console.WriteLine(gracze[0]);

⚙️ 13. Metody

Metoda to fragment kodu, który możemy wielokrotnie wywoływać.

static void Przywitaj() { Console.WriteLine("Witaj!"); } Przywitaj();

📥 14. Parametry metod

Metoda może przyjmować dane poprzez parametry.

static void Przywitaj(string imie) { Console.WriteLine("Cześć " + imie); } Przywitaj("Karol");

📤 15. return

return pozwala zwrócić wynik z metody.

static int Dodaj(int a, int b) { return a + b; } int wynik = Dodaj(5, 3); Console.WriteLine(wynik);

🏗️ 16. Klasy

Klasa jest szablonem, na podstawie którego możemy tworzyć obiekty.

class Gracz { public string Nick; public int Punkty; }

👤 17. Obiekty

Obiekt jest konkretną instancją klasy.

Gracz gracz = new Gracz(); gracz.Nick = "PlayerGG"; gracz.Punkty = 100; Console.WriteLine(gracz.Nick);

🧬 18. Dziedziczenie

Dziedziczenie pozwala stworzyć klasę, która korzysta z elementów innej klasy.

class Zwierze { public void Jedz() { Console.WriteLine("Jem!"); } } class Pies : Zwierze { public void Szczekaj() { Console.WriteLine("Hau!"); } }

🎮 19. Mini projekt

Stwórzmy prosty system punktów gracza.

int punkty = 0; punkty += 50; punkty += 25; Console.WriteLine("Punkty: " + punkty); if (punkty >= 50) { Console.WriteLine("🏆 Dobry wynik!"); }

🚀 20. Projekt końcowy

Gratulacje! Ukończyłeś podstawowy kurs C#. Teraz możesz spróbować stworzyć własną aplikację albo prostą grę.

using System; class Program { static void Main() { Console.WriteLine("=========================="); Console.WriteLine(" LEARNCODESGG C#"); Console.WriteLine("=========================="); Console.Write("Podaj nick: "); string nick = Console.ReadLine(); Console.WriteLine(); Console.WriteLine("Witaj, " + nick + "!"); Console.WriteLine("Ukończyłeś kurs C#! 🚀"); } }
