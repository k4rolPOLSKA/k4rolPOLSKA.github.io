🌐 Czym jest HTML?

HTML jest językiem używanym do tworzenia struktury stron internetowych.

Dzięki HTML możemy tworzyć nagłówki, teksty, obrazki, linki, przyciski oraz wiele innych elementów.

<h1>Witaj w LearnCodesGG!</h1>

🧠 Quiz

Do czego służy HTML?

📝 Nagłówki i tekst

HTML posiada sześć poziomów nagłówków:

h1 jest największym nagłówkiem, a h6 najmniejszym.

<h1>Największy nagłówek</h1> <h2>Mniejszy nagłówek</h2> <h3>Jeszcze mniejszy</h3> <p>To jest zwykły tekst.</p>

🧠 Quiz

Który nagłówek jest największy?

🔗 Linki

Do tworzenia linków używamy znacznika <a>.

<a href="https://example.com"> Otwórz stronę </a>

🧠 Quiz

Który znacznik tworzy link?

🖼️ Obrazki

Do dodawania obrazków używamy znacznika <img>.

<img src="obrazek.jpg" alt="Mój obrazek">

📋 Listy

HTML pozwala tworzyć listy uporządkowane i nieuporządkowane.

<ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul>

📊 Tabele

Tabele pozwalają przedstawiać dane w wierszach i kolumnach.

<table> <tr> <th>Język</th> <th>Poziom</th> </tr> <tr> <td>HTML</td> <td>Podstawowy</td> </tr> </table>

📝 Formularze

Formularze pozwalają użytkownikowi wprowadzać dane.

<form> <input type="text" placeholder="Twoje imię"> <button> Wyślij </button> </form>

📦 Div

Element div służy do grupowania elementów strony.

<div> <h2>LearnCodesGG</h2> <p>Nauka programowania</p> </div>

🏷️ Klasy HTML

Klasy pozwalają później stylować elementy za pomocą CSS.

<p class="tekst"> Hello World! </p>

🎨 Czym jest CSS?

CSS służy do nadawania wyglądu stronie internetowej.

Możemy zmieniać kolory, rozmiary, odstępy, pozycję elementów i wiele więcej.

body { background: black; color: white; }
