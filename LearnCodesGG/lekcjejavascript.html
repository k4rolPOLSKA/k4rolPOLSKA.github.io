🟨 1. Czym jest JavaScript?

JavaScript to język programowania używany między innymi do tworzenia interaktywnych stron internetowych.

console.log("Witaj w JavaScript!");

🧠 Quiz

Do czego często używa się JavaScript?

🖥️ 2. console.log()

console.log() pozwala wyświetlać informacje w konsoli przeglądarki.

console.log("Hello World!"); console.log(123); console.log(10 + 20);

📦 3. Zmienne

Zmienne pozwalają przechowywać dane. W JavaScript często używamy let i const.

let imie = "Karol"; let wiek = 13; console.log(imie); console.log(wiek);

🔒 4. let i const

let pozwala później zmienić wartość, natomiast const służy do wartości, której nie przypisujemy ponownie.

let punkty = 10; punkty = 20; const gra = "LearnCodesGG"; console.log(punkty); console.log(gra);

🔤 5. Typy danych

JavaScript obsługuje między innymi teksty, liczby, wartości logiczne, tablice i obiekty.

let imie = "Karol"; let wiek = 13; let online = true; console.log(imie); console.log(wiek); console.log(online);

➕ 6. Operatory

Operatory umożliwiają wykonywanie działań.

let a = 10; let b = 5; console.log(a + b); console.log(a - b); console.log(a * b); console.log(a / b);

❓ 7. if

Instrukcja if wykonuje kod, kiedy warunek jest prawdziwy.

let wiek = 18; if (wiek >= 18) { console.log("Jesteś pełnoletni"); }

🔀 8. if / else

else wykonuje kod, gdy warunek if nie został spełniony.

let wiek = 15; if (wiek >= 18) { console.log("Pełnoletni"); } else { console.log("Niepełnoletni"); }

🔢 9. else if

else if pozwala sprawdzić kolejny warunek.

let punkty = 80; if (punkty >= 90) { console.log("5"); } else if (punkty >= 70) { console.log("4"); } else { console.log("3"); }

🔁 10. Pętla for

Pętla for pozwala wykonywać fragment kodu określoną liczbę razy.

for (let i = 0; i < 5; i++) { console.log(i); }

🔄 11. Pętla while

while wykonuje kod tak długo, jak długo warunek jest prawdziwy.

let liczba = 1; while (liczba <= 5) { console.log(liczba); liczba++; }

📋 12. Tablice

Tablica może przechowywać wiele wartości.

let jezyki = [ "HTML", "CSS", "JavaScript" ]; console.log(jezyki[0]);

📦 13. Obiekty

Obiekt pozwala przechowywać dane w postaci właściwości.

let gracz = { nick: "PlayerGG", punkty: 100 }; console.log(gracz.nick); console.log(gracz.punkty);

⚙️ 14. Funkcje

Funkcja zawiera kod, który możemy wielokrotnie uruchamiać.

function przywitaj() { console.log("Witaj!"); } przywitaj();

📥 15. Parametry funkcji

Funkcja może otrzymywać dane poprzez parametry.

function przywitaj(imie) { console.log("Cześć " + imie); } przywitaj("Karol");

🌐 16. DOM

DOM pozwala JavaScriptowi zmieniać elementy znajdujące się na stronie.

document.querySelector("h1") .textContent = "LearnCodesGG!";

🖱️ 17. Kliknięcia

JavaScript może reagować na kliknięcia użytkownika.

document .querySelector("button") .addEventListener("click", function() { alert("Kliknięto przycisk!"); });

💾 18. localStorage

localStorage pozwala zapisywać dane w przeglądarce użytkownika.

localStorage.setItem( "nick", "PlayerGG" ); let nick = localStorage.getItem("nick"); console.log(nick);

🎮 19. Mini projekt

Stwórzmy prosty licznik punktów.

let punkty = 0; punkty++; console.log("Punkty:", punkty); punkty++; console.log("Punkty:", punkty);

Gratulacje! Ukończyłeś podstawowy kurs JavaScript.
