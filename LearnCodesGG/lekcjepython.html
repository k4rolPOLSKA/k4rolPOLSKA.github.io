🐍 1. Witaj w Pythonie

Python jest popularnym językiem programowania. Jest stosunkowo prosty do nauki i używany między innymi do tworzenia aplikacji, automatyzacji, analizy danych oraz sztucznej inteligencji.

print("Hello World!")

🖨️ 2. print()

Funkcja print() wyświetla informacje w konsoli.

print("Cześć!") print("Uczę się Pythona!") print(2026)

📦 3. Zmienne

Zmienna przechowuje wartość, którą możemy później wykorzystać w programie.

imie = "Karol" wiek = 13 print(imie) print(wiek)

🔢 4. Typy danych

Python posiada różne typy danych, np. tekst, liczby całkowite i liczby dziesiętne.

imie = "Karol" wiek = 13 cena = 19.99 gracz_online = True

➕ 5. Operatory

Operatory pozwalają wykonywać działania matematyczne.

a = 10 b = 3 print(a + b) print(a - b) print(a * b) print(a / b)

❓ 6. if

Instrukcja if pozwala wykonać kod tylko wtedy, gdy warunek jest prawdziwy.

wiek = 18 if wiek >= 18: print("Jesteś pełnoletni")

🔀 7. if / else

else wykonuje kod, kiedy warunek if nie jest spełniony.

wiek = 15 if wiek >= 18: print("Pełnoletni") else: print("Niepełnoletni")

🔀 8. elif

elif pozwala sprawdzić kolejny warunek.

punkty = 80 if punkty >= 90: print("5") elif punkty >= 70: print("4") else: print("3")

🔁 9. Pętla for

Pętla for pozwala powtarzać instrukcje.

for i in range(5): print(i)

🔄 10. Pętla while

while wykonuje kod tak długo, jak długo warunek jest prawdziwy.

liczba = 1 while liczba <= 5: print(liczba) liczba += 1

📋 11. Listy

Lista pozwala przechowywać wiele wartości.

jezyki = [ "Python", "Java", "C#" ] print(jezyki[0])

📖 12. Słowniki

Słownik przechowuje dane w parach klucz — wartość.

gracz = { "nick": "PlayerGG", "punkty": 100 } print(gracz["nick"])

⚙️ 13. Funkcje

Funkcja pozwala stworzyć fragment kodu, który możemy wielokrotnie uruchamiać.

def przywitaj(): print("Witaj!") przywitaj()

📥 14. Argumenty funkcji

Funkcja może przyjmować dane jako argumenty.

def przywitaj(imie): print("Cześć", imie) przywitaj("Karol")

📤 15. return

return pozwala zwrócić wynik z funkcji.

def dodaj(a, b): return a + b wynik = dodaj(5, 3) print(wynik)

📦 16. Moduły

Moduły pozwalają korzystać z gotowych funkcji znajdujących się w innych plikach.

import random liczba = random.randint(1, 10) print(liczba)

⚠️ 17. Obsługa błędów

try i except pozwalają obsługiwać błędy podczas działania programu.

try: liczba = int(input("Podaj liczbę: ")) print(liczba) except ValueError: print("To nie jest liczba!")

⌨️ 18. input()

input() pozwala pobrać tekst wpisany przez użytkownika.

imie = input("Jak masz na imię? ") print("Cześć", imie)

🎮 19. Mini projekt

Stwórzmy prosty program, który sprawdzi liczbę punktów gracza.

punkty = int(input("Ile masz punktów? ")) if punkty >= 100: print("🏆 Gratulacje!") else: print("💪 Graj dalej!")
